# C++ Basics

Ejemplo minimo de repositorio educativo C++ preparado para agentes.

## Objetivo

Implementar pequenas funciones y validar el comportamiento con un test de compilacion simple.

## Validacion

```bash
mkdir -p build && g++ -std=c++17 -I src tests/test_sumar_pares.cpp -o build/test_sumar_pares && ./build/test_sumar_pares
```
