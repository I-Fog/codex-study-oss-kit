# AGENTS.md

## Contexto

Ejemplo de practica basica en Python para ensenar estructura, tests y revision con agentes.

## Flujo esperado

- Miramos primero `README.md`, despues `tests/` y finalmente `src/`.
- Dejamos cualquier cambio validado con `python -m unittest discover -s tests`.
- Si falta un requisito, lo apuntamos en la seccion de pendientes en vez de inventarlo.
