# Contributing

Thanks for helping improve `codex-study-oss-kit`.

## Local checks

Run:

```powershell
python -m unittest discover -s tests
python -m codex_study_oss_kit --help
```

## Contribution focus

Good first contributions:

- More educational templates.
- Better repository audit checks.
- Real examples from public teaching repositories.
- GitHub Action examples for automated audit reports.

Avoid adding network calls or model-provider integrations before the offline CLI is stable.
